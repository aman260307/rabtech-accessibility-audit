# RabTech Accessibility Audit

## Project Overview

This project was created for the RabTech Academy internship Task 02:
Accessibility Baseline & Repository Architecture Audit.

## Website Audited

https://www.india.gov.in/

## Audit Tools

- Google Chrome Lighthouse
- Manual Keyboard Testing

## Accessibility Score

89/100

## Key Findings

- ARIA roles missing required parent elements
- Insufficient colour contrast
- List items not contained within appropriate parent elements

## Repository Structure

- client/ - Frontend layer
- server/ - Backend/API layer
- docs/ - Audit and architecture documentation
- tests/ - Accessibility testing documentation
- screenshots/ - Audit evidence
- accessibility-audit.xlsx - Audit findings

## Testing
